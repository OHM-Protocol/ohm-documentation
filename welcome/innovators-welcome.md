# OHM Documentation

Central public documentation for OHM Protocol: introductions, briefs, the technical whitepaper, and reference material.

This repo is for:

- Welcome materials for innovators and builders.
- Condensed explanations of the Abundance Protocol and OHM architecture.
- The evolving **technical whitepaper** that connects the vision to the protocol and economic design.
- High-level briefs you can share with collaborators, funders, and contributors.

## Key Documents

- **Innovator’s Welcome**  
  A personal welcome from Birthe and an orientation to how to start contributing.  
  See: [`welcome/innovators-welcome.md`](./welcome/innovators-welcome.md)

- **The Abundance Protocol – Developer Brief**  
  A condensed, developer-facing summary of the core concepts, architecture, and vision.  
  See: [`briefs/abundance-protocol-brief.md`](./briefs/abundance-protocol-brief.md)

- **OHM Protocol – Technical Whitepaper (Evolving Draft)**  
  A deeper, more technical and economic description of the OHM Protocol.  
  It translates the vision in *The Abundance Protocol* into protocol components, data flows, and economic mechanisms.  
 See: `whitepaper/ohm-technical-whitepaper.md`

- **Full Book: The Abundance Protocol**  
  For the complete philosophical and narrative context, see the full book:  
  [The Abundance Protocol – Amazon link](https://www.amazon.nl/Abundance-Protocol-Operating-Regenerative-English-ebook/dp/B0FWJRF3JS)
