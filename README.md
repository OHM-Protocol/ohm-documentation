# OHM Documentation

Central public documentation for OHM Protocol CIC: introductions, briefs, and reference material.

This repo is for:

- Welcome materials for innovators and builders.
- Condensed explanations of the Abundance Protocol and OHM architecture.
- High-level briefs you can share with collaborators, philanthropic funders, and contributors.

## Key Documents

- **Innovator’s Welcome**  
  A personal welcome from Birthe and an orientation to how to start contributing.  
  See: [`welcome/innovators-welcome.md`](./welcome/innovators-welcome.md)

- **The Abundance Protocol – Developer Brief**  
  A condensed, 5-page developer-facing summary of the core concepts, architecture, and vision.  
  See: [`briefs/abundance-protocol-brief.md`](./briefs/abundance-protocol-brief.md)

- **Full Book: The Abundance Protocol**  
  For the complete philosophical and technical context, see the full book:  
  [The Abundance Protocol – Amazon link](https://www.amazon.nl/Abundance-Protocol-Operating-Regenerative-English-ebook/dp/B0FWJRF3JS)

- **MVP Frontend Walkthrough**  
  For a visual tour of the current OHM MVP frontend (12 minutes), see:
 [OHM MVP Frontend Walkthrough](https://youtu.be/_QxRG7OENpg?si=BrD6XE47hqekAeRu)
